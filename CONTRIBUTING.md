# Contributing

This repo follows the TwentyOne.Life engineering guardrails. Key rules for every change:

- **Identity:** commits and PRs carry only the `TwentyOne.Life` identity - no personal name/email/handle,
  no `Co-Authored-By:` trailers, no tool "generated by" lines.
- **Design before code:** anything non-trivial gets a short doc in `docs/design/` (template provided);
  architectural calls get an ADR in `docs/adr/`.
- **Clear, minimal, sovereign code:** smallest correct diff; comments say *why* not *what*; no filler or
  speculative abstraction; no telemetry/phone-home; pinned + SHA/GPG-verified dependencies.
- **Tests:** every bug fix ships a regression test; crypto/header logic gets known-answer vectors;
  CI must be green before merge.
- **Releases are signed:** every release ships `SHA256SUMS` + a detached GPG signature (see `release.yml`).

## Definition of Done
- [ ] Design doc/ADR if non-trivial
- [ ] Minimal, slop-free diff matching surrounding style
- [ ] Tests added (regression for fixes) and CI green
- [ ] Docs/README/PLAN updated
- [ ] No PII, no personal identity/trailers, no secrets, no unpinned/unverified deps
- [ ] Linked issue, reviewed, `main` still releasable
